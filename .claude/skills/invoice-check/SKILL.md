# 發票檢查與整理

把一疊發票整理成 Excel，並做金額與統編檢查。

## 流程

### 1. 逐頁讀取發票
- PDF 用 Read 分批讀（`pages: "1-3"`），一頁常有 2～4 張發票，每張都要記下。
- 每張發票記錄：日期（西元 YYYY-MM-DD；民國年 +1911）、發票號碼（字軌＋8 碼）、類型（電子發票／三聯式(手開)／收銀機三聯式）、賣方名稱、賣方統編、買方統編、各品項（品名、數量、單位、單價、金額）、銷售額、營業稅、總計、備註（PO 號、客戶編號等）。
- 手寫或印章看不清楚時，先用中文大寫金額、數量×單價等方式交叉推算；仍不確定的，寫在 `note` 裡，例如「品名為手寫，請核對」。
- 賣方名稱以**印章或列印的統編**為準。名稱字跡容易看錯（例如「寓承」誤看成「萬承」），第 3 步會用統編反查改正。

### 2. 寫成 JSON
存到 scratchpad，格式：

```json
{
  "buyer_name": "志瑞螺絲企業有限公司",
  "buyer_id": "25095094",
  "period": "115年9-10月份",
  "tax_rate": 0.05,
  "invoices": [
    {
      "date": "2026-10-22", "number": "FP36699498", "type": "電子發票",
      "seller_name": "東日實業股份有限公司 台中營業所", "seller_id": "09326730",
      "buyer_id": "25095094",
      "sales": 1241, "tax": 62, "total": 1303, "tax_kind": "應稅",
      "items": [{"name": "不銹鋼螺絲", "qty": 6.416, "unit": "KG", "price": 193.42, "amount": 1241}],
      "note": ""
    }
  ]
}
```

- 金額照發票所載填寫，不要自己改成算出來的數字，讓腳本去比對。
- 沒有單價的品項（例如「1批」、只寫金額的運費）`price` 填 `null`。
- `tax_kind` 可填 `應稅`、`零稅率`、`免稅`；非應稅不檢查 5%。

### 3. 執行檢查
```bash
python3 -I .claude/skills/invoice-check/scripts/check_invoices.py <invoices.json> <輸出.xlsx>
```
- 會印出 JSON：張數、合計、`problems`（每個問題的發票號碼、類別、說明）、`registry`（每個統編的經濟部登記資料）。
- 統編查詢使用 `data.gcis.nat.gov.tw`（經濟部商工登記開放 API）。若連線被擋（403 / CONNECT tunnel failed），在雲端環境用 `get_environment` 確認後，以 `update_environment` 把 `data.gcis.nat.gov.tw` 加入白名單；無法加入就改用 `--no-lookup`，並告訴使用者統編沒有上網核對。

### 4. 處理問題
- **名稱不符**：回去看該張發票原圖，若是自己看錯（字形相近），把 JSON 的 `seller_name` 改成登記名稱後重跑；若發票本身就寫不同名稱，保留原樣並在 `note` 說明。
- **加總／稅額／品項不符**：先回原圖確認是不是抄錯；確定是發票本身的問題，就保留原值，在回報中明確指出。
- **統編檢查碼錯誤**：通常是看錯一個數字，回原圖重看。
- **經濟部查無登記**：「○○營業所」這類通常是財政部稅籍統編，不在經濟部資料內，屬正常情況，註明即可。
- 改完後重跑，直到剩下的問題都是發票本身的問題或已說明的情況。

### 5. 重算公式並交付
若有 xlsx skill，執行它的 `scripts/recalc.py <輸出.xlsx>` 讓公式帶出數值（沒有也沒關係，Excel 開啟時會自動計算）。

用 SendUserFile 把 Excel 傳給使用者。Excel 分頁：
- **發票總表**：一張一列、依日期排序，有問題的列標紅，底部有合計公式。
- **品項明細**：每個品項一列。
- **統編查核**：經濟部登記名稱、狀態、地址與比對結果。
- **檢查結果**：所有待確認事項。

### 6. 回報
先講結論（張數、銷售額／稅額／總計合計、有沒有問題），再列：
- 金額有問題的發票（號碼＋說明）
- 名稱已依統編更正的賣方（原本 → 登記名稱）
- 無法核對的統編與原因
- 仍需對照原件的手寫欄位
