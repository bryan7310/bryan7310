### 1.2 決定價格的屬性（成本系統的欄位）

依影響大小排列：

1. **直徑**：材料用量跟直徑平方成正比，影響最大。
2. **長度**：價格幾乎是長度的一次函數（見 3.1）。
3. **材質／強度等級**：鐵 → 中碳 8.8 → 合金 12.9 → SUS304 → SUS316，每一級約 1.3–2 倍。
4. **表面處理**：電鍍約 +10–15%，鍍鎳約 +20–30%。
5. **頭型**：丸、皿、大扁同價；只有蝶頭、六角華司面、圓頭等特殊頭明顯較貴。
6. **牙型**：公制粗牙是基準；細牙、UNF、全牙特製品屬特製，價格另列。
7. **包裝／數量**：整盒與散裝、整包與零買，差 3–20%。

## 2. 廠商報價型態

| 型態 | 計算方式 | 廠商 |
|---|---|---|
| 牌價 × 折數 | 牌價本多年不改，漲跌價只改折數表 | 東日（牌價 2017 年、折數 2026 年）、虹瑩、金同利、鑫城、久允、長驥 |
| 實價 | 直接標單價，不打折 | 豐通、順聯 |
| 時價（按公斤） | 每公斤單價，附每公斤個數 | 阡阡華司、鑫城鋼構螺栓（A325 56–57 元/kg、S10T 70 元/kg） |

**實際比價要看淨價，不能看牌價。** 同一份牌價表不同等級只差在折數，例如鑫城外六角 12.9 級與 8.8 級共用一張價格表，折數 79 對 52，所以淨價固定差 79÷52 = 1.52 倍。

## 3. 報價邏輯（從數據推回來）

### 3.1 價格 = 固定費 + 每 mm 單價 × 長度

把 743 組「同廠商、同品名、同材質、同直徑、不同長度」的牌價各做直線回歸，**R² 中位數 0.98**，價格幾乎就是長度的一次函數：

```
牌價 ≈ a（頭部／成型固定費） + b（每 mm 材料加工費） × 長度
```

例：東日 SUS304 外六角 M10，15 mm 10.8 元、50 mm 19.5 元、100 mm 32.0 元，每 5 mm 約加 1.2–1.5 元。

偏離直線的三種情況：

- **最低價**：短尺寸有底價。久允 M4 丸頭 4–8 mm 都是 15 元／100 支。
- **非標準短尺寸較貴**：虹瑩 M6×6 100 元，比 M6×8 的 68 元還貴。
- **超長跳價**：超過一般打頭機能做的長度（約 10–15 倍直徑）就跳價。虹瑩 M6×100 439 元，M6×110 955 元；久允 M4 35 mm 30 元，40 mm 起 40、48、58 元。

### 3.2 每 mm 單價跟直徑平方成正比，也就是按重量計價

每 mm 單價 b 對直徑 d 做 log 回歸，得到 `b ∝ d^p`，83 組系列的 **p 中位數 1.85**：

- M8 以上的外六角、內六角、馬車螺絲，p 約 1.9–2.1，幾乎完全按重量計價。
- 小螺絲（久允機械牙、鐵板牙）p 約 1.1–1.6，加工費占比高，材料比重低。

### 3.3 換算每公斤淨價

把長度每增加 1 mm 的淨價，除以那 1 mm 的鋼材重量（螺紋段約為公稱截面的 85%），得到**每公斤淨價（中位數，NT$/kg）**：

| 材質 | ≤M4 | M5–M6 | M8–M10 | M12–M16 | ≥M18 |
|---|---|---|---|---|---|
| 鐵／低碳鋼 | 100 | 80 | 67 | 59 | 62 |
| 中碳鋼（8.8） | – | 111 | 98 | 92 | 98 |
| 合金鋼（12.9） | 365 | 152 | 126 | 112 | 102 |
| SUS304 | 192 | 171 | 183 | 206 | 282 |
| 彈簧鋼 | 167 | 103 | 143 | 185 | – |

解讀：

- 碳鋼和合金鋼**越粗每公斤越便宜**，因為加工費攤到更多重量上。到 M12 以上會收斂到「線材價格＋熱處理＋利潤」，約 60（鐵）、95（中碳）、105（合金）元/kg。
- SUS304 大尺寸每公斤反而更貴。M20 以上多半是鍛造品（東日鍛造品折數 30，一般品 25），加工方式不同。
- 可以當**訂製品材料加工費的參考值**（見第 6 節）。

### 3.4 頭部固定費

固定費 a 換算成「相當於幾倍直徑長度的桿身價格」：

| 頭型 | 倍徑 | 頭型 | 倍徑 |
|---|---|---|---|
| 六角 | 1.1 | 皿頭、大扁頭、馬車頭 | 2.3 |
| 半圓頭內六角 | 1.4 | 丸頭 | 3.0 |
| 內六角 | 1.5 | 六角華司面 | 4.0 |
| 無頭（止付） | 1.8 | 圓頭 | 4.9 |
| 喇叭頭 | 1.9 | 蝶頭 | 8.5 |

意思是：一支 M8 丸頭螺絲，頭部大約等於多 24 mm（3 × 8）桿身的價錢。小螺絲的頭部占比比大螺絲高。

### 3.5 頭型、表面處理、材質的加價比例（淨價比）

**頭型**（同廠同規格）：

- 丸頭＝皿頭＝大扁頭（久允 1.00／1.03，金同利 0.97／1.10），牌價表通常一格寫兩種頭。
- 虹瑩：有頭內六角當 1，皿頭 1.16、半圓頭 1.12、無頭 1.04。
- 金同利：六角十字 1.48 倍丸頭，六角華司面 1.25 倍。
- 蝶型螺絲約 5–7 倍同尺寸一般螺絲。

**表面處理**：

| 比較 | 加價 |
|---|---|
| 黑身／白皮 → 電鍍（順聯、鑫城、久允） | +11–14% |
| 未處理 → 鍍鋅、染黑（長驥） | +18% |
| 鍍鋅 → 鍍鎳（豐通、長驥） | +21–23% |
| 再加熱處理（長驥） | +13% |
| 阡阡附註：六價五彩 | 每公斤 +9 元，須滿 80 kg |
| 阡阡附註：零散電鍍 | 每桶 600 元（六價）、800 元（三價） |

**材質／強度等級**（相同公制規格比淨價）：

| A → B | 淨價倍數 | 比對筆數 |
|---|---|---|
| 外六角 低碳 4.6 → 中碳 8.8 | 1.30 | 150 |
| 外六角 中碳 8.8 → 合金 12.9 | 1.52 | 218 |
| 外六角 中碳 8.8 → SUS304 | 2.12 | 228 |
| 十字機械牙 鐵 → SUS304 | 2.6（M2–M2.6 約 4.3） | 66 |
| 內六角 合金 12.9（虹瑩）→ SUS304（東日） | 2.38 | 173 |
| SUS204 → SUS304（東日壁虎） | 1.26 | 19 |
| SUS304 → SUS316（東日、長驥） | 1.9–2.2 | 122 |

**廠商通路差異**比材質還大：虹瑩 12.9 級合金內六角（48–50 折）比鑫城 8.8 級中碳內六角（84 折）**還便宜 15%**。同樣是 SUS304 十字機械牙，金同利比東日貴約 10%。

### 3.6 數量、包裝條款

| 條款 | 廠商 |
|---|---|
| 整盒 20 折，不足一盒 23 折（約 +15%） | 東日小螺絲 |
| 整件散裝 76 折、盒裝 79 折（約 +4%） | 鑫城 |

## 4. 成本評估公式（標準品）

```
淨價 = 牌價(直徑, 長度) × 折數(廠商, 類別, 材質, 尺寸區間)
       × 表面處理係數 × 包裝係數
```

查不到牌價的標準品，用 3.1–3.5 的係數推估：

```
淨價 ≈ [ 頭部倍徑(頭型) × d + L ] × 0.85 × π/4 × d² × 密度 × 每公斤淨價(材質, 直徑區間)
       × 表面處理係數 × 包裝係數
```

套用到系統的建議：

1. 已有牌價：照現在的「牌價 × 折數」，多家時取最低淨價。
2. 牌價表缺的長度：用同系列的 a、b 線性內插（`analysis/output/長度回歸.csv` 已有每組 a、b）。
3. 牌價表缺的直徑或材質：用每公斤淨價和材質倍數推估，並標示「估算」。

## 6. 特殊訂製品（有圖面）估價方法：待校正

訂製品通常照下面的結構報價。每一項的參考值都要用實際圖面報價單校正：

```
單價 = 材料費 + 成型費 + 二次加工費 + 熱處理 + 表面處理 + 模具／開機費 ÷ 數量 + 利潤
```

| 項目 | 估算方式 | 參考值（來自標準品，需校正） |
|---|---|---|
| 材料費 | 毛胚重量 × 線材單價 ÷ 材料利用率 | 毛胚重量用頭部＋桿身體積算；利用率冷打約 90–95%，車削約 40–60% |
| 成型（打頭、輾牙） | 按重量或每支計價 | 第 3.3 節每公斤淨價可當上限 |
| 二次加工 | 每道工序每支計價：車削、銑扁、鑽孔、攻牙、滾花 | 需要圖面報價單 |
| 熱處理 | 按公斤計價 | 長驥資料：+13% |
| 表面處理 | 按公斤計價，有最低訂量或每桶費 | 阡阡資料：五彩 +9 元/kg（≥80 kg），零散 600–800 元／桶 |
| 模具、開機費 | 固定費，除以訂購數量 | 需要圖面報價單 |
| 非標準規格加成 | 細牙、非標準長度、全牙特製 | 虹瑩細牙、全牙特製品、超長跳價約 1.5–2 倍 |

- 外形尺寸（直徑、長度、頭部尺寸）
