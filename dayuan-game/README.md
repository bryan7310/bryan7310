# 大元國小大冒險（3D 校園遊戲）

依照大元國小的空拍圖與平面圖做成的 3D 校園冒險遊戲。用瀏覽器打開 `index.html` 就能玩（需要網路載入 Three.js）。

- 到中庭找**校長**報到 → 攻擊力加倍、隨時補體力
- **體育老師**（操場）：躲避球連發　**自然老師**（生態池）：泡泡護盾　**護理阿姨**（活動中心）：補滿體力
- 找 3 位**同學**組隊，一起丟躲避球打作業怪、蚊子怪、搗蛋鬼
- 打倒 15 隻怪獸後，**考卷大魔王**會在操場出現

操作：WASD／方向鍵走路（Shift 跑步）、滑鼠拖曳轉視角、點擊或空白鍵丟球、E 對話；手機用左下搖桿與右下按鈕。

修改請編輯 `src.html`，再執行 `python3 build.py` 產生內嵌校徽的 `index.html`。
