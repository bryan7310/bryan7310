# 螺絲查價系統

單一網頁檔 `index.html`，用瀏覽器直接開啟即可使用（手機、電腦皆可），不需要安裝或架伺服器。

## 功能
- **查價**：七個下拉選單（材質、電鍍、螺絲類別、頭型、牙系〔公制／英制〕、直徑、長度）互相連動篩選，選項旁顯示符合筆數；也可再輸入品名 / 規格 / 品號搜尋（`m4x20`、`M4×20`、全形字都能找到）。顯示牌價、折扣、淨價。
  - 頭型、牙系、直徑、長度若牌價表沒有這幾欄，會從品名與規格自動判斷（例：`M10×1.25×40` → 公制、直徑 M10、細牙、長度 40）。
- **重複品項**：不同牌價表有相同品項時，查價結果與報價單會並列「供應商、折數、淨價」，並標出最低價。判斷方式：品名、規格、材質、電鍍、頭型都相同；或不同供應商在同一類別中規格、材質、電鍍、頭型相同。
- **報價單**：把查到的品項加入並填數量，可設定整單再折、加 5% 營業稅，一鍵複製報價文字。
- **牌價管理**
  - 大類別各自設定折扣：`65`、`6.5`、`0.65` 都代表 65 折；`65 95` 代表 65 折再 95 折。
  - 單一品項可設定個別折扣，優先於類別折扣。
  - 匯入牌價表時填寫「供應商」與牌價日期，品項會標註供應商；「取代」只會取代同一供應商的品項。
  - 匯入牌價表：Excel（.xlsx/.xls）、CSV，或從 Excel 複製貼上。
    - **清單格式**：第一列為欄位名稱（品號、品名、規格、材質、電鍍、頭型、牙系、直徑、牙型、長度、單位、牌價、折扣、備註、類別），自動對應，可手動調整。
    - **尺寸矩陣**：第一列為直徑（M3、M4…）、第一欄為長度，交叉格為牌價，自動展開成 `M4×10` 等規格。
  - 備份 / 還原（JSON）。

## 單價單位
系統一律以 1 PCS（每支／每個）計價：每 100 支、每 100 個、每籮 144 支的牌價自動除以包裝數；華司每公斤價格用每公斤個數換算。原牌價與原單位顯示在品項說明。只有東日斜紋釘、每包 5 公斤的平面／四角華司沒有每公斤個數，仍以每公斤計價。

## 資料儲存
資料存在該瀏覽器的 localStorage，換裝置或清除瀏覽資料前請先備份。

## 查價專用版
`readonly.html` 只能查價、加入報價單、複製報價文字，沒有「牌價管理」，資料固定用內建牌價。
更新 `index.html` 或內建牌價後執行 `python3 data/build_readonly.py` 重新產生。

## 訂製螺絲報價系統（`custom-quote.html`）
非標準件（客製螺絲）用的報價工具，一樣用瀏覽器直接開啟。流程：上傳圖檔 → 計算重量 → 分析加工程序 → 各工序成本 → 報價單。

- **上傳圖檔**
  - **圖片（JPG／PNG）、PDF**：框選零件側視外形，輸入圖面上的零件總長（或用比例尺工具畫一條已知長度的線），系統沿軸向逐點量直徑，以迴轉體積分計算體積，並自動拆成分段輪廓。另有量測工具。
  - **DXF（2D CAD）**：直接用 CAD 座標計算；可勾選要用的圖層（關掉尺寸、中心線、標題欄），支援完整外形或半剖面。
  - **STL（3D 模型）**：以三角網格精確計算實體體積、表面積、外框。
- **重量**：三種來源可切換——參數模板（內六角圓柱頭、六角頭、法蘭頭、圓頭、沉頭、盤頭、無頭，可帶入 ISO 標準頭部尺寸）、分段輪廓（圓柱、圓錐、六角、四角、圓頂，可設內孔／六角孔、螺紋、需車修）、STL 實體。螺紋段以節徑計算體積（滾牙前後材料體積不變）。顯示單重、千支重、本批總重與投料重。
- **加工程序分析**（每一項都可改成強制啟用／不需要）
  - 成型：冷打成型或棒材全車削，「自動」會比較兩者成本取低，並檢查冷打外徑、長度、頭部鐓粗比是否可行。
  - 車修：偵測溝槽／退刀槽、段差、中段錐面、鑽孔、指定車修段、精密公差。
  - 滾牙：有螺紋段即需要（M36 以上改車牙）。
  - 熱處理：8.8／10.9／12.9 級、SUS410、合金鋼自動判斷為調質；也可手動指定滲碳、退火、固溶。
  - 電鍍：依表面處理；10.9 級以上電解電鍍自動加驅氫。
- **工序成本欄位**：材料（元/kg、損耗）、冷打（元/千支、模具費、開機費）、車修／車削（秒/支、機台費率、換線費）、滾牙（秒/支、費率、牙板費、開機費）、熱處理與電鍍與驅氫（元/kg、每批最低收費）、篩選包裝、運費，以及自訂費用。欄位留空就用自動值（灰字顯示）。
- **報價**：不良率、管銷、利潤；成本佔比；數量級距報價（各級距自動選工法）；可列印／存成 PDF 的報價單、複製報價文字、歷史紀錄（JSON／CSV 匯出）。
- **單價設定**：材質密度與單價、熱處理、電鍍、冷打級距、機台費率等都可修改並匯出備份。預設單價僅供參考，請依實際行情調整。
