# 螺絲查價系統

單一網頁檔 `index.html`，用瀏覽器直接開啟即可使用（手機、電腦皆可），不需要安裝或架伺服器。

## 功能
- **查價**：七個下拉選單（材質、電鍍、螺絲類別、頭型、牙系〔公制／英制〕、直徑、長度）互相連動篩選，選項旁顯示符合筆數；也可再輸入品名 / 規格 / 品號搜尋（`m4x20`、`M4×20`、全形字都能找到）。顯示牌價、折扣、淨價。
  - 頭型、牙系、直徑、長度若牌價表沒有這幾欄，會從品名與規格自動判斷（例：`M10×1.25×40` → 公制、直徑 M10、細牙、長度 40）。
- **重複品項**：不同牌價表有相同品項時，查價結果與報價單會並列「供應商、折數、淨價」，並標出最低價。判斷方式：品名、規格、材質、電鍍、頭型都相同；或不同供應商在同一類別中規格、材質、電鍍、頭型相同。
- **報價單**：把查到的品項加入並填數量，可設定整單再折、加 5% 營業稅，一鍵複製報價文字。
- **牌價管理**
  - 大類別各自設定折扣：`65`、`6.5`、`0.65` 都代表 65 折；`65 95` 代表 65 折再 95 折。
  - 單一品項可設定個別折扣，優先於類別折扣。
  - 匯入牌價表時填寫「供應商」與牌價日期，品項會標註供應商；「取代」只會取代同一供應商的品項。
  - 匯入牌價表：Excel（.xlsx/.xls）、CSV，或從 Excel 複製貼上。
    - **清單格式**：第一列為欄位名稱（品號、品名、規格、材質、電鍍、頭型、牙系、直徑、牙型、長度、單位、牌價、折扣、備註、類別），自動對應，可手動調整。
    - **尺寸矩陣**：第一列為直徑（M3、M4…）、第一欄為長度，交叉格為牌價，自動展開成 `M4×10` 等規格。
  - 備份 / 還原（JSON）。

## 內建牌價表
- 久允螺絲牌價表（115/06/26 起，1,371 筆）
- 順聯螺帽散裝／盒裝報價單（112/01/01 起，514 筆）

第一次開啟就會載入；之後新增的供應商會自動補進已存的資料。說明與判讀假設見 [`data/README.md`](data/README.md)。「牌價管理 → 重新載入內建牌價」可還原成內建版本（不影響自己新增的資料）。

## 資料儲存
資料存在該瀏覽器的 localStorage，換裝置或清除瀏覽資料前請先備份。
