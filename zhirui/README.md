# 志瑞螺絲作業平台（伺服器版）

把原本的「志瑞進銷存」與「志瑞螺絲作業平台」整合成一套：一台公司 Windows 電腦當伺服器，其他電腦、手機用瀏覽器連進來，所有人看同一份資料、即時同步、伺服器自動備份。

安裝與操作步驟見 [`安裝步驟.md`](安裝步驟.md)。整合評估與規劃見 [`../docs/整合規劃.md`](../docs/整合規劃.md)。

## 結構

```
zhirui/
  啟動伺服器.bat      雙擊啟動（Windows）
  匯入舊資料.bat      把舊版共用資料夾的 JSON 匯進來（可重複執行）
  安裝步驟.md
  server/
    app.py            HTTP 伺服器：靜態網頁、JSON API、登入、long-polling 即時同步、每日備份
    db.py             SQLite 資料層（文件式集合 + 版本號；歷史單據另表）
    import_legacy.py  舊資料匯入
  web/                新介面（純 HTML/CSS/JS，不需建置）
    index.html, css/app.css
    js/app.js         外框：登入、導覽、路由、全站搜尋
    js/core/          api（伺服器）、store（資料與即時同步、本機快取）、calc（庫存／餘額／成本）、pricing（查價）、ui（對話框等）、util
    js/modules/       各作業：總覽、查價、報價、銷貨、訂貨排程、傳真紀錄、圖面、進貨、庫存、標籤列印、應收、郵寄掛號、應付、發票、支票開立、支票登記、收付款、報表、基本資料、設定
    legacy/drawing.html  原螺絲圖面工具（嵌入使用）
  pricing/            各供應商牌價 JSON（匯入時載入）
  data/               執行後產生：zhirui.db、backup/（不進版控）
```

## 流程串接

- 銷貨單 → 應收帳款自動按月、按客戶彙總（可手動調整）→ 勾選已收款。
- 銷貨單 → 一鍵開發票（帶入統編、品項、稅額）；「待開」清單列出未開發票的銷貨單。
- 進貨單 → 應付帳款自動彙總 → 填開票金額或直接「開支票」→ 支票開立套印。
- 查價加入「報價單草稿」→ 建立正式報價單（牌價品項自動建成商品）→ 轉成銷貨單。
- 採購單自動出現在訂貨排程；排程完成提醒轉進貨單。
- 銷貨單「標籤」勾選商品 → 標籤列印（豐餘標籤依每包數量拆張、一般標籤）。
- 採購單／詢價單／報價單「傳真」→ 黑白傳真稿（可加封面）→ 傳真紀錄。
- 應收帳款勾選客戶 → 郵寄掛號（地址標籤 5×4 cm、大宗掛號函件執據）。
- 客戶／供應商只有一份主檔，舊作業平台的簡稱做為別名；對不上的在「基本資料 → 名稱對應」處理。

## 開發、測試

```bash
python3 server/import_legacy.py --src <舊共用資料夾> --data /tmp/zrdata --reset
python3 server/app.py --port 8080 --data /tmp/zrdata
```
瀏覽器開 http://localhost:8080/ 。
