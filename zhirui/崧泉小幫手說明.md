# 崧泉小幫手

把崧泉企業的「鼎新 B2B 協作平台」（http://211.20.149.149/DSCB2B ，志瑞是廠商 5B0001）和志瑞 ERP 接起來。
程式：`server/b2b_helper.py`（只用 Python 標準函式庫），在**主機的 Windows 桌面**執行。

## 它做什麼

1. **抓未回覆的採購單 → 客戶訂單（要老闆確認）**
   每 10 分鐘讀一次崧泉平台「採購單回覆」。有新的採購單，就做成待確認檔；ERP「客戶訂單」頁最上面會出現
   「崧泉平台　有 N 張待確認 →」，點進去看過、按「確認寫入」才會變成客戶訂單（客戶單號＝崧泉的採購單號）。
   - 品項用崧泉的品號對商品資料的「客料號」。對不到的先用文字存，出貨前在訂單上補選。
   - 同一張採購單裡已經回覆過的項次也會一起帶進來。
   - 崧泉後來改數量、交期：訂單還沒出貨的，會列成「變更」再請老闆確認；已經出貨的只提醒，不會動。
   - 先在崧泉平台回覆、後在 ERP 確認，也沒關係，待確認檔會留著。
   - 程式只看、不回覆。**交期要老闆自己到崧泉平台回覆**；沒回覆的採購單，崧泉平台不給建出貨單。

2. **銷貨單 → 崧泉出貨單（自動送出）**
   在 ERP 把崧泉的客戶訂單按「出貨（轉銷貨單）」存檔後，等 10 分鐘（留時間改單），程式到崧泉平台
   「出貨單建立」選那張採購單的項次、填銷貨單的數量、備註填「志瑞銷貨單 單號」，核對第 3 步畫面和銷貨單一樣才按「完成」，
   再到「出貨單查詢」確認真的建好了。
   - **第一張會停在第 3 步**，把視窗叫到最前面，請老闆自己核對、按「完成」。這一張成功後才全自動。
   - 數量超過崧泉的未交數量、項次對不到、畫面內容不一樣：不送，在「客戶訂單」頁列出原因。
   - 按了完成卻查不到出貨單：**不會重送**（怕重複），列出來請老闆到崧泉平台看。
   - 只處理「小幫手啟用之後才建」而且「由崧泉平台匯入的客戶訂單轉出來」的銷貨單，以前的不會補送。

3. **出貨標籤**
   出貨單建好後，把崧泉平台產生的出貨標籤 PDF 抓回來（`web/pending/b2b_labels/出貨單號.pdf`，要登入 ERP 才看得到），
   「客戶訂單」頁的「已建崧泉出貨單」旁邊有「🏷 印標籤」，點開就能列印。

## 登入

崧泉平台有圖形驗證碼，程式不能自己登入。小幫手會開一個**專用的 Edge 視窗**，老闆在裡面登入一次，
之後靠每 10 分鐘抓一次維持連線。連線斷了（例如主機重開機）：視窗會跳到最前面，「客戶訂單」頁也會顯示要重新登入。
帳號密碼只打在那個視窗裡，程式不讀、不存。那個視窗不要關。

## 安裝（主機上做一次）

1. 更新程式（跟平常一樣從 GitHub 拉）。網頁有改，瀏覽器按 Ctrl+F5。
2. 雙擊 `設定崧泉小幫手開機啟動.bat`（會順便啟動）。只想先試，雙擊 `啟動崧泉小幫手.bat`。
3. 在跳出來的 Edge 視窗登入崧泉平台。
4. 到 ERP「客戶訂單」頁，最上面出現「崧泉平台　剛剛抓過…」就是好了。

## 設定：`data/b2b_helper.json`（第一次執行自動產生，改完重開小幫手）

| 項目 | 預設 | 說明 |
|---|---|---|
| `customer` | 崧泉 | ERP 客戶名稱裡要有的字，只能對到一家 |
| `interval_min` | 10 | 每幾分鐘抓一次（不要超過 15，不然崧泉的連線會過期） |
| `ship` | true | 要不要自動建崧泉出貨單 |
| `ship_wait_min` | 10 | 銷貨單存檔後等幾分鐘才送 |
| `ship_auto_submit` | true | false＝每一張都停在第 3 步等人按「完成」 |
| `ship_merge` | true | 同一個出貨日的銷貨單合成一張崧泉出貨單（一車一張）；還有銷貨單剛存檔在等待時，整批先不送 |
| `label` | true | 要不要抓出貨標籤 |
| `label_kind` | 4 | 條碼類別：1 內箱、3 外箱、4 全部 |
| `label_size` | 77 | 77＝7cm×7cm 標籤紙、A4＝A4 紙 |

紀錄檔：`%LOCALAPPDATA%\zhirui\b2b_helper.log`。狀態記在 `data/b2b_state.json`（刪掉它＝重新開始，之前送過的銷貨單會被當成沒送過，**不要亂刪**）。

## 測試

`python server/b2b_helper.py --once --dry`：跑一輪就結束，不碰「出貨單建立」。加 `--data`、`--web` 可以指到測試用的資料夾。

## 還沒實地驗證的地方（2026-11-26）

- 出貨單建立的第 1、2 步（查詢、勾選、改數量）在崧泉平台實際試過；**第 2 步按「下一步」到第 3 步、以及按「完成」之後的畫面**還沒實際跑過，
  所以第一張一定要有人看著按。
- 順帶一提：每次抓「採購單回覆」頁，崧泉那邊會記「第一次讀取時間」，等於崧泉看得到志瑞已經讀過採購單。
