# 志瑞螺絲作業平台（伺服器版）安裝步驟

整套只需要一台公司的 Windows 電腦當伺服器，其他電腦、手機用瀏覽器連進來即可。

## 一、伺服器電腦（只做一次）

1. **安裝 Python 3**
   到 <https://www.python.org/downloads/windows/> 下載 Python 3.12 以上，安裝時務必勾選 **Add python.exe to PATH**。
   不需要安裝其他套件。
2. **放好程式**
   把整個 `zhirui` 資料夾複製到伺服器電腦，例如 `C:\zhirui`。
   資料會存在 `C:\zhirui\data\zhirui.db`（一個檔案），備份預設在 `C:\zhirui\data\backup\`。
3. **匯入舊資料**
   雙擊 `匯入舊資料.bat`，把 BeeStation 上舊版的共用資料夾拖進視窗，按 Enter，第一次選 `Y`（清空後匯入）。
   會匯入：商品、客戶／供應商、倉庫、現行單據、約 4.6 萬張歷史單據、查價牌價、應收、應付、發票、支票登記、訂貨排程、操作日誌。
   結尾會列出「對不上客戶／供應商的名稱」，之後在平台的「基本資料 → 名稱對應」裡勾選即可。
4. **啟動伺服器**
   雙擊 `啟動伺服器.bat`。視窗顯示 `http://localhost:8080/` 就表示啟動了。
   第一次用瀏覽器打開會要求建立第一個帳號（管理者），之後在「設定 → 帳號」新增其他帳號（共 3 個）。
5. **讓其他電腦連得到**
   - 幫這台電腦設 **固定 IP**（路由器 DHCP 保留，或在網路設定手動指定，例如 `192.168.1.10`）。
   - Windows 防火牆允許 8080：以系統管理員身分開啟「命令提示字元」執行
     ```bat
     netsh advfirewall firewall add rule name="志瑞平台 8080" dir=in action=allow protocol=TCP localport=8080
     ```
   - 其他電腦、手機瀏覽器打開 `http://192.168.1.10:8080/`（換成實際 IP）。可以「加到主畫面」或「安裝成應用程式」。
6. **開機自動啟動（建議）**
   開啟「工作排程器」→ 建立基本工作 → 觸發程序選「電腦啟動時」→ 動作「啟動程式」：
   - 程式：`C:\zhirui\啟動伺服器.bat`
   - 起始位置：`C:\zhirui`
   建立後開啟該工作的內容，勾選「不論使用者登入與否均執行」、「以最高權限執行」。
   電源選項設定成「永不睡眠」。

## 二、備份

- 伺服器每天固定時間（預設 12:00，可在「設定 → 備份」改）自動把資料庫壓縮成一個 zip 存到備份資料夾，保留最近 30 份。
  **不需要有人開著網頁**。備份資料夾可以改成 BeeStation 上的路徑（例如 `Z:\志瑞備份`）。
- 也可以在「設定 → 備份」按「立即備份」。
- 還原：關掉伺服器，把 zip 裡的 `zhirui.db` 覆蓋 `data\zhirui.db`，再啟動。

## 三、更新程式

把新的 `zhirui` 資料夾覆蓋舊的（`data` 資料夾不要動），重新啟動伺服器即可。

## 四、常見問題

- **其他電腦連不上**：確認伺服器 `啟動伺服器.bat` 視窗還開著、IP 正確、防火牆規則已加。
- **忘記密碼**：在伺服器電腦打開 `http://localhost:8080/`，用另一個帳號登入到「設定 → 帳號」重設；若三個都忘了，刪除 `data\zhirui.db` 裡的 users 很麻煩，請直接聯絡維護者。
- **可以用手機嗎**：可以，同一個 Wi-Fi 下用瀏覽器開伺服器網址即可。公司外面要連需另外設定（之後再做）。
